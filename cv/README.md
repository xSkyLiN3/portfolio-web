# Fuente del CV

`CV_Cristobal_Vergara_ATS.docx` es la fuente editable del currículum publicado en el
portafolio. Su diseño prioriza lectura humana y compatibilidad con sistemas ATS:

- una página en tamaño Letter;
- una sola columna y orden de lectura lineal;
- viñetas reales, sin tablas, fotografía ni iconos;
- enlaces verificables a portafolio, GitHub, LinkedIn, proyectos y credencial;
- métricas y límites consistentes con la documentación pública de los proyectos.

Para publicar una revisión:

1. editar este DOCX;
2. exportarlo a PDF conservando los enlaces;
3. revisar visualmente la página completa y comprobar la extracción de texto;
4. reemplazar `public/CV_Cristobal_Vergara.pdf`;
5. ejecutar las verificaciones del repositorio antes del despliegue.

El PDF público es un artefacto revisado. No debe reconstruirse desde versiones históricas
ni desde generadores que contengan contenido anterior del currículum.
